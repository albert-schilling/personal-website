Bardery

AI-generated, illustrated stories where the reader decides what happens next

In active development View on GitHub

Bardery writes and illustrates a story part by part, like an illustrated children's book. Each part ends in a choice: the reader picks one of three suggested paths or describes their own, and Bardery continues from there. Readers can go back to any earlier choice to branch off a new storyline, or have the story read aloud. Stories are written for a profile's age, from toddlers to young adults.

It is also a public reference for building a production-ready AI application, including the engineering around the features: a layered architecture, tests, evaluations for the AI workflows, observability, infrastructure as code and CI/CD.

Under the hood

Multi-modal generation pipeline

Story text streams to the app as it is generated. Each part then gets an illustration and optional narration, run as background jobs with retries and fallbacks. Earlier illustrations and hero portraits are passed in as reference images to keep characters consistent.

Child-safety guardrails

Each age band has its own content policy. An LLM classifier decides whether a reader's free-text input is fine, should be gently reinterpreted or must be blocked. Provider content filters run at the strictest level on every model call.

Semantic search

Stories are embedded and searchable by meaning, using pgvector in the same Postgres database that also holds the job queue. That leaves one place to back up and one place to delete a family's data from.

Evals

A custom eval harness scores story scenarios per age band and language, including a red-team set. It combines deterministic checks with an LLM judge calibrated against human labels, and compares results against a baseline.

Privacy by design

All hosting and every AI model run in the EU. No story or prompt content is sent to telemetry, and the app has no trackers.

Cloud and delivery

Azure Container Apps that scale to zero, provisioned with Terraform. GitHub Actions run lint, type, test, migration, infrastructure and security checks before staged releases.

Built with:
TypeScript, Expo (React Native), Node.js, tRPC, Postgres with pgvector, Azure OpenAI, FLUX.2, Azure Speech, Terraform, OpenTelemetry
